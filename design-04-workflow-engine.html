Workflow Engine Internals

Event-Driven Side Effects
When a workflow transitions state, the engine emits events:
workflow.submitted → Notification Hub sends alerts to approvers
workflow.approved → Module-specific handler locks entity
workflow.rejected → Notifies submitter with comments
workflow.escalated → Re-assigns to next-level role
Bulk Operations
Teacher rubrics require bulk approve/reject. The engine supports:
bulkApprove(entity_ids[]) — Approve multiple in one transaction
bulkReject(entity_ids[], comment) — Reject with shared comment
All within a single DB transaction for consistency.
Escalation Cron
A scheduled job runs every hour:
1. Find workflows in PENDING state > auto_escalate_hours
2. Re-assign to escalate_to role
3. Send escalation notification
4. Log in audit trail
Audit Trail
Every state transition is recorded in audit_trail JSONB array:
{ action, by, role, at, comment, from_state, to_state }
Immutable append-only. Queryable for compliance reports.
