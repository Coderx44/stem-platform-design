Section 10: AI Curriculum Module (LMS)

Teacher training LMS — external content + built-in quizzes, progress tracking, certificates

Purpose

Teachers learn STEM curriculum on the platform, pass assessments, then teach it to students offline. Students don't use this module directly. This is a licensed module — tenants enable it based on their plan.

Decision pending: Two content creation approaches under consideration. Both share the same course structure, quiz builder, progress tracking, and data model. They can coexist — tenants could use both.

Approach A: SCORM-Based Content

Admins create content in external tools, upload SCORM packages to the platform

How It Works
1. Admin creates content in H5P / Lumi / Articulate (external)
2. Exports as SCORM .zip → uploads to platform
3. Backend extracts to S3
4. Teacher opens lesson → SCORM player (iframe) loads content
5. SCORM API reports completion, score, time back to platform
6. Resume support — teacher picks up where they left off
Free Authoring Tools
• H5P — browser-based, 50+ content types, free
• Lumi — desktop app, works offline, exports SCORM, free
• Adapt Learning — responsive courses, open-source
• iSpring Free — converts PowerPoint to SCORM

Pros

  • Rich interactive content (branching, simulations, embedded quizzes)
  • Industry standard — content portable across LMS platforms
  • Free authoring tools available (H5P, Lumi)

Cons

  • Requires external tools (learning curve for NGO admins)
  • Content creation is a separate step outside the platform
  • SCORM player adds frontend complexity

Approach B: Built-in Content Builder

Admins build courses directly in the platform — no external tools needed

How It Works
1. Admin uses in-platform editor to create lessons
2. Rich text editor (markdown or WYSIWYG) for text content
3. Embed YouTube videos or upload videos to S3
4. Upload PDFs/slides as viewable resources
5. Build quizzes inline with lesson flow
6. All content managed in one place
Content Types
• Rich text — formatted text with images
• Video — YouTube embed or uploaded to S3
• Documents — PDF, slides (viewable/downloadable)
• Quizzes — MCQ, T/F, short answer (auto-graded)

Pros

  • Self-contained — no external tools needed
  • Lower barrier for NGO admins
  • Simpler to build and maintain

Cons

  • Less interactive than SCORM (no branching, simulations)
  • More dev effort to build the editor
  • Content not portable to other LMS platforms
